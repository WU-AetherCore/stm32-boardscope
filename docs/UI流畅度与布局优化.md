# V1.2 流畅度与 128×64 布局优化

日期：2026-10-09。本次保留原工程备份 backup/ui-smooth-before，修改仍位于 V1.2。

## 卡顿处理

- PB6/PB7 改为硬件 I2C1 400 kHz，中断发送，不占用六路 UART DMA。初始化仍同步发送少量命令，正常刷新异步发送。
- 画布、在途快照和已完成缓存独立；只发送变化区间。忙时跳过提交，下一周期取最新画布，避免排队积累旧画面。
- UI 使用 vTaskDelayUntil，16 ms 固定周期；动画按实际帧间隔收敛。打开/返回菜单直接定位，取消阻塞退场动画。
- Debug 中图形库、应用 UI、文字适配和 I2C 中断热路径使用 -O2，保留调试符号。

16 ms 是 UI 处理周期，不能等同于 OLED 每秒完整刷新 62.5 次。整屏 I2C 数据传输需要约 25 ms；局部变化通常更少。传输期间 UI 仍可处理输入。

## 尺寸与文字

列表固定每行 16 px、每屏四行；选择框宽 121 px，保留右侧滚动条。摄像机根据实际选中行定位，避免返回页面后滚动位置漂移。

原来文字宽度被截为 122，实际文字继续绘制，造成宽度判断失真。现用真实 UTF-8 字模测宽并裁剪到可用容器。长数字使用 5×7 ASCII 字体；中文标签必要时缩短并显示两个点，优先完整保留冒号后的数字。UART 各统计拆为独立行，避免 RX/TX/错误多个数字挤在一行。

编辑弹窗外框为 (3,2,122,60)，标题、数值框、操作提示分区；数值框宽由实际字宽计算，限制 58–112 px。最大 Flash 地址 0xFFFFF0、温度上限、亮度和串口编号均使用此布局。

## 工程与验证

新增 astra_text.c 和 astra_editor.cpp，中文注释说明裁剪、数字优先和窗口布局。I2C 文件取自 ST 官方 stm32f4xx-hal-driver v1.8.2，与现有 HAL 版本一致，原 BSD-3-Clause 许可保留。

I2C1 由 astra_display.c 手工初始化，CubeMX .ioc 仍保留 OLED 引脚标签。重新生成工程时，应保留此驱动和 HAL_I2C_MODULE_ENABLED、INCLUDE_vTaskDelayUntil 设置；GPIO 初始化后由显示驱动切换 PB6/PB7 到 AF4。

Debug/Release 编译和链接内存统计检查通过。桌面测试使用真实 U8g2 和字库逐像素验证裁剪边界、4294967295 完整显示；UART 状态机与协议测试同时通过。

实际板上数据和截图保存在 validation。调试器输入只验证软件导航；实体旋转编码器的手感仍由实际操作体验确认。

调试器观测：编辑弹窗一次绘制 5533 μs，当前启动以来绘制最大值 6940 μs；变化帧传输最大值 24509 μs，I2C 错误计数 0。数据来自 validation/smooth-timing.log，包含任务抢占，不是纯函数基准，也不代表实体编码器手感已验证。

最终固件复位后 COM6/115200 收到 14 组完整快照，间隔 1002–1004 ms；UI 心跳速率 61.75–62.87 次/秒。启动阶段前两组传感器无效，后续 12 组有效，最后温度 25 ℃、湿度 60%。OLED/UI 状态均为0，UART错误与丢包为0，五路继电器命令关闭。堆空闲/最低 12704/12704 B，UI 最小栈余量 2964 B。串口已释放，验证日志为 validation/smooth-final-runtime.json。
