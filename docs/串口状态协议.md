# BoardScope 串口状态协议 v1

UART1 为 115200 / 8N1 / 无流控，PA9 TX、PA10 RX。每 1000 ms 截取一组状态，共 26 条 JSON 行；传输整组约 130 ms，所有行共享序号 s。
通信任务独立于 OLED 初始化，每 5 ms 服务队列。发送拥堵时保留未发送行，错过周期累计到 end，不覆盖半组快照。

```json
{"s":1,"t":"begin","v":[1,1000,168000000,1000]}
{"s":1,"t":"end","v":[0,26]}
```

s 是 uint32 序号，t 是记录类型，v 是按下面顺序排列的非负整数。每行不超过 128 字节，包括 CRLF。
begin 至 end 形成完整快照；接收端应检查序号、版本、类型顺序、记录数与串口/按键/端口编号。缺行时不要混合显示不同组数据。
设备重启后序号和运行时间重新开始，毫秒和序号均允许 uint32 回绕。普通命令回复可插在 JSON 行之间，监控器忽略非 JSON 行。

| 类型 | v 字段顺序 | 每组行数 |
|---|---|---|
| `begin` | 协议版本、运行时间(ms)、系统时钟(Hz)、上报周期(ms) | 1 |
| `sensor` | 温度(℃)、湿度(%)、最近采样有效、成功采样距今(ms)、温度上限(℃)、温度报警、电压预设(mV)、电压实测有效 | 1 |
| `relay` | 继电器1命令、继电器2命令、继电器3命令、继电器4命令、继电器5命令、蜂鸣器命令、报警使能 | 1 |
| `flash` | 通信有效、JEDEC ID、容量(B)、状态寄存器 | 1 |
| `memory` | FLASH已用(B)、FLASH总量(B)、RAM已用(B)、RAM总量(B)、CCM已用(B)、CCM总量(B) | 1 |
| `sections` | text(B)、data(B)、bss(B)、dec(B) | 1 |
| `heap` | 堆总量(B)、堆空闲(B)、历史最小空闲(B)、任务数、通信任务最小栈余量(B) | 1 |
| `ui` | OLED状态码、UI状态码、UI心跳、UI最小栈余量(B) | 1 |
| `key` | 按键编号、短按次数、长按次数、双击次数 | 3 |
| `can` | 接收次数、最后ID、最后长度、HAL错误码 | 1 |
| `can_data` | 数据字节0、数据字节1、数据字节2、数据字节3、数据字节4、数据字节5、数据字节6、数据字节7 | 1 |
| `uart` | 串口编号、接收字节、发送完成字节、TX队列拒绝包、RX队列丢包、错误次数、发送失败次数 | 6 |
| `uart_state` | UART1排队/回显编码、UART2排队/回显编码、UART3排队/回显编码、UART4排队/回显编码、UART5排队/回显编码、UART6排队/回显编码 | 1 |
| `gpio` | 端口编号(A=0)、IDR输入寄存器、ODR输出寄存器 | 5 |
| `end` | 错过上报周期数、记录总数 | 1 |

所有容量/内存/栈值单位为字节。静态 RAM 包含 FreeRTOS 堆数组，不应再叠加堆已用量。
uart_state 每个值低 4 位为待发送包数，bit4 为回显开关。TX 是 DMA 完成字节，不是对端确认。
sensor 成功采样距今为 4294967295 表示尚无成功采样；有效为 0 时温湿度可能是历史值。
电压是原工程预设，电压实测有效固定为 0。继电器和蜂鸣器是软件命令，GPIO 是寄存器采样，不能替代继电器触点反馈。
OLED/UI 的 0 表示 OK；CAN 未收到帧时的零值不是外部链路验证结果。Flash 值为最近查询缓存；GPIO/其他任务数据按字段采样，并非总线同时锁存。
协议只能报告当前驱动已暴露的数据；新增传感器或状态需同时扩展 firmware、协议和监控器。

## 中文电脑窗口

安装 Python 3.10+（含 Tkinter），在工程根目录运行：

```powershell
python -m pip install -r tools/requirements.txt
python tools/boardscope_monitor.py
```

选择 COM6，点击连接。实时状态页按模块显示所有字段，原始数据页保留最近串口文本。
连接前先关闭其他程序占用的串口。三秒无完整快照显示过期提示，断线后可重连。
窗口读取不会发送控制命令；原有 STATUS / HELP / RELAY / UI 命令仍可通过普通串口助手发送。

## 任务资源

Board_Comm 为 Normal 优先级、512 栈字（2048 B），状态数组固定在 BSS。
通信模块唯一调用 Board_UartService；UI 不再调度 UART 队列，防止多消费者争用。
每组约 1.2 KB，UART1 占用约 10%–12% 带宽，历史 TX 缓冲仍仅保存最近 256 B。
